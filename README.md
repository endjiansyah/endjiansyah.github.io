# Endjiansyah — Personal Portfolio & Field Notes

Situs portofolio pribadi dan *field notes* milik **Endjiansyah** (Software Engineer, Product Manager & Educator). Dibuat dengan performa tinggi, desain visual modern, serta struktur konten yang terorganisir.

---

## 🚀 Tech Stack

- **Framework**: [Astro v4](https://astro.build/) (Static Site Generation)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *Inter* - SIL Open Font License)
- **Content Management**: Astro Content Collections (Markdown & Schema Validation)
- **SEO & Structured Data**: OpenGraph, Schema.org Person JSON-LD, Sitemap

---

## 📁 Struktur Proyek

```text
.
├── src/
│   ├── components/      # Komponen UI (Navbar, Footer, WorkCard, StoryCard, EducationCard, VideoEmbed)
│   ├── content/         # Content collections (works, stories, modules, playlists)
│   ├── layouts/         # Base Layout & styling global
│   └── pages/           # Halaman utama (index, works, stories, learning, 404)
├── public/              # Aset statis & gambar
├── astro.config.mjs     # Konfigurasi Astro
└── tailwind.config.mjs  # Konfigurasi Tailwind CSS
```

---

## 🛠️ Perintah Pengembangan

Menjalankan perintah dari direktori utama proyek:

| Perintah | Aksi |
| :--- | :--- |
| `npm install` | Menginstal seluruh dependensi |
| `npm run dev` | Menjalankan server pengembang di `localhost:4321` |
| `npm run build` | Membangun bundel produksi statis ke `./dist/` |
| `npm run preview` | Meninjau hasil *build* produksi secara lokal |
