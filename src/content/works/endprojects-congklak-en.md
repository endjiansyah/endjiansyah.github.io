## About This Project

Endprojects-Congklak is a game-based learning game that brings the traditional congklak game into a digital experience. The project is designed to make learning more interactive, rooted in local culture, and accessible through play.

### The Learning Concept

Players learn the rules and strategies of congklak through playing activities, challenges, and instant feedback. This digitization helps the traditional game stay relevant while opening space to build numeracy, strategic thinking, and problem-solving skills.

During development, this project was built with AI as a partner for idea exploration, implementation iteration, and play-experience refinement. Design decisions, feature structure, and the learning direction remain curated independently by me.
